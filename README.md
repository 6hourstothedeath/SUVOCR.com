# SUVOCR — OCR-блокнот

Приложение для телефона: фотография → текст → проверка ошибок → отправка на почту.
Работает как PWA: ставится иконкой на домашний экран, после первой загрузки работает офлайн,
распознавание идёт в самом телефоне (компьютер и сервер не нужны).

**Открыть:** https://6hourstothedeath.github.io/SUVOCR.com/

## Что умеет

- съёмка камерой (несколько страниц подряд) и мультивыбор фото из галереи;
- предобработка снимка: уменьшение, серый, контраст, автоопределение поворота (0/90/180/270°),
  выравнивание наклона страницы;
- OCR на устройстве: `tesseract.js` + модели `rus` и `eng`;
- абзацы по межстрочным интервалам, отделение заголовков, склейка абзаца, разорванного между страницами;
- замена латинских букв-двойников (В/В, С/С, Р/Р) на кириллицу;
- проверка ошибок через API: Яндекс.Спеллер или LanguageTool, с заменой по одной и «исправить все»;
- отправка: письмо с заполненным адресатом (короткий текст) или «Поделиться» файлом `.txt` (длинный);
- страницы и текст сохраняются в браузере (IndexedDB) и восстанавливаются после перезагрузки.

## Как поставить на телефон

1. Открыть ссылку в Chrome на Android.
2. Дождаться первой загрузки (~38 МБ: движок, модели, определение поворота) — лучше по Wi-Fi.
3. Меню Chrome (три точки) → «Установить приложение».
4. Разрешить доступ к камере и файлам.

## Структура

```
index.html            экран приложения
app.js                логика: OCR, абзацы, проверка, отправка
style.css             оформление
sw.js                 офлайн-режим
manifest.webmanifest  установка иконкой
icons/                иконки 192 / 512 / maskable
vendor/               tesseract.js, wasm-ядро, модели rus+eng+osd
test/                 тестовые страницы
```

## Ограничения

- рукописный текст распознаётся плохо (ограничение tesseract);
- таблицы читаются как обычный текст;
- проверка ошибок отправляет текст в Яндекс/LanguageTool — для медицинских и личных
  документов в настройках есть режим «не проверять»;
- пароль от почты в приложении не используется: статическая страница не может подключиться
  к SMTP, а в публичном репозитории пароль был бы виден всем.

## Разработка

Исходники и скрипты сборки/публикации — в папке проекта у автора: `tools/build.mjs`
(сборка vendor), `tools/deploy.mjs` (публикация на GitHub Pages), `tools/serve.mjs`
(локальный сервер).
